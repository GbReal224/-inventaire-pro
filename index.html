Sauvegarde locale

L’application utilise la base de données locale du navigateur (IndexedDB). Les données ne sont pas envoyées sur Internet.

Important : garde occasionnellement une sauvegarde JSON dans Fichiers/iCloud. Cela protège ton inventaire si Safari ou iOS supprime les données d’un site.

Installation sur iPhone

  1. Ouvre l’adresse de l’app dans Safari.
  2. Appuie sur Partager.
  3. Choisis Sur l’écran d’accueil.
  4. Ouvre ensuite l’app depuis son icône.
